## 🚀 What I ship — Order Flow

One license key, every screen in the shop. Main keeps working **offline** (48 h license grace); the internet is a courier, never a dependency. Shop data stays on the shop's devices.

| Client | Runs on | What it is |
|---|---|---|
| 📱 **Android app** | Main + stations | Main server on the shop Wi-Fi; waiter, kitchen, cashier, driver and manager stations join free by QR |
| 💻 **Windows app** | Windows 10/11 | The same Main as a portable `order_flow.exe`, prints through the Windows printer list |
| 🌐 **Web app** | iPhone / any browser | The full POS at [jathol.org/app](https://jathol.org/app) — installable, offline-first |
| 🧾 **Guest QR menu** | Customer phones | Scan, order, track, call the waiter — English/Urdu, no app; repeat orders join the same bill |
| ☁️ **Cloud room + licensing** | Cloudflare | Encrypted relay between devices (AES-GCM, nothing stored), license keys, plans and per-feature access |

**Feature depth:** table map · kitchen screen · split payment & khata · refunds · deals, combos & happy hour · cash drawer handover · staff attendance & pay · stock, recipes & food margin · suppliers & purchase orders · wastage · loyalty · reservations · delivery dispatch · X/Z reports · thermal printing (network, Bluetooth, Windows) · menu import from a photo or PDF · English + اردو with full right-to-left.
